# Deletion ledger

No production deletion is approved or performed by this audit.

| Candidate | Current decision | Evidence required before removal |
|---|---|---|
| Existing speech adapter/queue | KEEP | A future coordinator must reuse their behavior; only superseded coordination can retire after manual/live/preview/call regression proof |
| Independent selector catalog fetch state | Potential later replacement | Shared query handles connection change, refresh, errors and unmount; both settings panels verified |
| Durable/direct streaming split | KEEP pending capability audit | External/media semantics and all callers supported by a single chosen owner; no data loss/replay regression |
| Existing tool loops | KEEP | Backend-specific behavior traced and contracts proven before any extraction/removal |
| General Studio artifact renderer | KEEP | Dedicated companion scope does not authorize removing general Studio artifacts |
| Training/Recipe Studio custom additions | KEEP | Outside companion scope |
| Sibling ErisHub/VoiceForge/Video-chat trees | KEEP inspectable | Owner deliberately retires them after replacement behavior is proven |

Do not treat a deferred/rejected port as permission to delete its source application. No temporary compatibility shim was introduced.
